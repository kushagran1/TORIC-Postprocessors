# TORIC-Postprocessors
## 2-D and 1-D Post-Processing Codes

This repository contains Python-based post-processing tools for the analysis and visualization of simulation results. The **2-D post-processor** provides spatial visualization of simulation data through contour plots, field distributions, and two-dimensional power distributions. The **1-D post-processor** enables extraction, plotting, and comparison of one-dimensional power profiles and quantities along psi coordinates.
